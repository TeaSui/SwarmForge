# Plan 05-01: CDK Infrastructure

**Phase:** 5 — Deployment & Observability
**Wave:** 1 (foundational infrastructure)
**Requirements:** INF-01, INF-02, INF-03, INF-04

## Goal

Define the core AWS infrastructure using CDK: VPC, ECS Cluster, EFS, SQS, DynamoDB, and Secrets Manager.

## must_haves

- VPC with public and private subnets.
- ECS Cluster with Fargate capacity provider.
- EFS File System with Access Point for ECS task mounting.
- SQS Queue with associated Dead Letter Queue (DLQ).
- DynamoDB tables: `swarmforge-tasks` and `swarmforge-idempotency`.
- IAM Roles for ECS tasks with least-privilege access.
- Secrets Manager integration for API keys.
