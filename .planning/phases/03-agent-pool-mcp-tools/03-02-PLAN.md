## Goal

Instantiate Coder and Reviewer with strict role boundaries, deterministic prompt contracts, and controlled tool access.

## must_haves

- Reviewer prompt optimized for regression/security/style checks
- Tool scopes are role-separated (write vs review)
- Agent outputs follow fixed envelope: `summary`, `changes`, `risks`, `next_actions`
