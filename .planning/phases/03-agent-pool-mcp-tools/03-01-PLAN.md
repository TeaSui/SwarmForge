# Plan 03-01: MCP Server Connections

**Phase:** 3 — Agent Pool & MCP Tools
**Wave:** 1 (foundational)
**Requirements:** MCP-01, MCP-02, MCP-03

## Goal

Provide production-safe tool adapters for GitHub, Jira, and shell so all agent actions run through auditable, policy-checked interfaces.

## must_haves

- Shared MCP client with retry/backoff and structured errors
- GitHub wrapper supports branch/commit/PR operations with idempotency keys
- Jira wrapper supports read issue, post comment, update status
- Shell wrapper restricts cwd and command allowlist
- Every tool call emits audit event `{task_id, agent, tool, result}`

## Tasks

<task id="1">
Implement `tools/mcp_client.py` with timeout, retry, and standardized response schema.
</task>

<task id="2">
Implement `tools/github.py` and `tools/jira.py` wrapper methods with typed payloads.
</task>

<task id="3">
Implement `tools/shell.py` sandbox rules: cwd constraint, blocked commands, timeout.
</task>

<task id="4">
Add `tests/test_tools.py` for happy-path, retryable failures, and denied command scenarios.
</task>

## Verification

```bash
pytest tests/test_tools.py -v
```

Success criteria:
- [ ] Tool wrappers return consistent success/error contracts
- [ ] Unsafe shell commands are denied with explicit reason
- [ ] Tool audit events include correlation metadata
- [ ] Tests pass
