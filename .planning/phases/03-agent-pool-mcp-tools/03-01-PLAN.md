# Plan 03-01: MCP Server Connections

**Phase:** 3 — Agent Pool & MCP Tools
**Wave:** 1 (foundational for all agents)
**Requirements:** MCP-01, MCP-02, MCP-03

## Goal

Establish reliable connections to GitHub and Jira MCP servers. Implement wrapper classes for core tools (read/write file, create PR, post comment) that agents can use.

## must_haves

- `tools/mcp_client.py` — generic client to connect to any MCP server
- `tools/github.py` — GitHub specific wrappers (create PR, write file)
- `tools/jira.py` — Jira specific wrappers (post comment, read ticket)
- `tools/shell.py` — Local shell/file ops restricted to project workspace
- Tools return clear, structured results (success/fail + output)
