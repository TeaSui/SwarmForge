# Plan 02-04: Token & Cost Budget Manager

**Phase:** 2 — Orchestration & LLM
**Wave:** 2 (parallel with 02-02 and 02-03)
**Requirements:** ORC-05, ORC-06

## Goal

Enforce hard execution safety: every task is bounded by token, cost, and runtime limits, with explicit termination states.

## must_haves

- Task budget contains `token_soft`, `token_hard`, `usd_soft`, `usd_hard`, `max_runtime_minutes`
- `BUDGET_SOFT_WARNING` is emitted once when soft thresholds are crossed
- Task terminates with `BUDGET_EXCEEDED` when hard cap is reached
- Budget state persists after each LLM/tool call
- Termination reason is human-readable for Jira/Slack notifications
