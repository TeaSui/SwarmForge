# Plan 02-04: Token Budget Manager

**Phase:** 2 — Orchestration & LLM
**Wave:** 2 (parallel with 02-02 and 02-03)
**Requirements:** ORC-05, ORC-06

## Goal

Implement budget guardrails for every task so token usage is tracked, persisted, and hard-stopped when over configured limits.

## must_haves

- Token usage is accumulated per task (`input`, `output`, `total`)
- Usage is persisted to DynamoDB after each LLM call
- Over-budget tasks transition to `BUDGET_EXCEEDED` and stop execution
- Budget status is visible in orchestrator logs and task state

</task>
