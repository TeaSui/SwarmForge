# Plan 02-04: Token Budget Manager

**Phase:** 2 — Orchestration & LLM
**Wave:** 2 (parallel with 02-02 and 02-03)
**Requirements:** ORC-05, ORC-06

## Goal

Implement a token budget manager that tracks usage per task and kills any task that exceeds the configured limit. Integrate into the orchestrator so every LLM call passes through the budget check. Update DynamoDB with real-time token usage.

## must_haves

- `orchestrator/budget.py` — `TokenBudget` tracks per-task usage, raises `BudgetExceededException` when over limit
- `Orchestrator.dispatch()` catches `BudgetExceededException` → sets DynamoDB status to `BUDGET_EXCEEDED`
- Token usage persisted to DynamoDB `token_usage` field in the task record
- Integration with `LLMClient` (from 02-03) to update budget after every call

## Tasks

<task id="1">
Create `orchestrator/budget.py`:

```python
class BudgetExceededException(Exception):
    pass

class TokenBudget:
    def __init__(self, task_id: str, limit: int, state_manager):
        self.task_id = task_id
        self.limit = limit
        self.state = state_manager
        self.usage = {"input": 0, "output": 0, "total": 0}

    def update(self, usage: dict):
        self.usage["input"] += usage.get("input_tokens", 0)
        self.usage["output"] += usage.get("output_tokens", 0)
        self.usage["total"] += usage.get("total_tokens", 0)
        
        # Persist to DynamoDB immediately
        self.state.update_usage(self.task_id, self.usage)
        
        if self.usage["total"] > self.limit:
            raise BudgetExceededException(
                f"Task {self.task_id} exceeded token budget: {self.usage['total']} > {self.limit}"
            )
```
</task>

Update `orchestrator/state_manager.py` to add `update_usage`:

```python
    def update_usage(self, task_id: str, usage: dict):
        self.client.update_item(
            TableName=self.table,
            Key={"task_id": {"S": task_id}},
            UpdateExpression="SET token_usage = :u, updated_at = :t",
            ExpressionAttributeValues={
                ":u": {"M": {
                    "input": {"N": str(usage["input"])},
                    "output": {"N": str(usage["output"])},
                    "total": {"N": str(usage["total"])}
                }},
                ":t": {"S": datetime.now(UTC).isoformat()}
            }
        )
```
</task>
