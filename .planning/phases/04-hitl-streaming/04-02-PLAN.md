# Plan 04-02: HITL Approval Gate

**Phase:** 4 — Human-in-the-Loop & Streaming
**Wave:** 2 (depends on 04-01)
**Requirements:** HITL-01, HITL-02, HITL-03

## Goal

Enforce explicit human approval before protected actions (PR create/merge-like operations) with resumable state.

## must_haves

- `APPROVAL_PENDING` state persisted with approver channel metadata
- Protected action execution is blocked until approval decision is received
- Approval timeout transitions to safe terminal status (`APPROVAL_TIMEOUT`)
- Rejection path stores comments for feedback loop in 04-03
