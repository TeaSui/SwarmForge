# Plan 04-01: Streaming Output

**Phase:** 4 — Human-in-the-Loop & Streaming
**Wave:** 1 (foundation)
**Requirements:** OUT-01, OUT-02

## Goal

Stream real-time execution progress to Jira/Slack with correlation IDs so humans can monitor long-running autonomous tasks.

## must_haves

- Event bus emits lifecycle milestones: queued, started, delegated, tool_call, completed, failed
- Jira comments are throttled to avoid spam (e.g., max 1 per 20s per task)
- Final summary comment includes PR link, test/security outcome, and elapsed time
- Streaming failures do not break core task execution
