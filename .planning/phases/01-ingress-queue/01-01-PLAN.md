# Plan 01-01: FastAPI Service Skeleton

**Phase:** 1 — Ingress & Queue
**Wave:** 1 (no dependencies — first plan to execute)
**Requirements:** TRG-01, TRG-02, TRG-03, TRG-04

## Goal

Stand up a FastAPI service with three webhook endpoints (`/webhook/jira`, `/webhook/slack`, `/webhook/generic`) and a health check (`/health`). All endpoints perform HMAC signature validation and filter events. Return 200 immediately for all valid requests. SQS publishing is mocked/stubbed — wired in Plan 01-02.

## must_haves

- `/webhook/jira` accepts POST, validates HMAC-SHA256 `X-Hub-Signature` header, returns 200 in < 200ms
- `/webhook/slack` accepts POST, validates `X-Slack-Signature` + `X-Slack-Request-Timestamp`, returns 200
- `/webhook/generic` accepts POST with bearer token auth, returns 200
- `/health` GET returns `{"status": "ok", "version": "..."}` with 200
- Jira webhook only processes events where issue has an AI trigger label (configurable)
- Invalid signatures return 401
- All settings loaded via `pydantic-settings` from env vars

<task id="3">
Implement `api/webhooks/jira.py`:

```python
import hashlib, hmac
from fastapi import APIRouter, Request, HTTPException, BackgroundTasks
from config import settings

router = APIRouter()

def _validate_jira_signature(payload_bytes: bytes, signature_header: str | None):
    if not signature_header:
        raise HTTPException(status_code=401, detail="Missing signature")
    expected = "sha256=" + hmac.new(
        settings.JIRA_WEBHOOK_SECRET.encode(),
        payload_bytes,
        hashlib.sha256,
    ).hexdigest()
    if not hmac.compare_digest(expected, signature_header):
        raise HTTPException(status_code=401, detail="Invalid signature")

def _is_ai_task(payload: dict) -> bool:
    labels = payload.get("issue", {}).get("fields", {}).get("labels", [])
    return any(l.get("name") in settings.ai_labels_set for l in labels)

async def _publish_stub(payload: dict, source: str):
    # Stubbed — replaced by real SQS producer in Plan 01-02
    pass

@router.post("/jira")
async def jira_webhook(request: Request, background_tasks: BackgroundTasks):
    body = await request.body()
    _validate_jira_signature(body, request.headers.get("X-Hub-Signature-256"))
    payload = await request.json()
    if _is_ai_task(payload):
        background_tasks.add_task(_publish_stub, payload, "jira")
    return {"status": "accepted"}
```

<task id="5">
Write tests in `tests/test_webhooks.py`:

```python
import pytest, hmac, hashlib, time, json
from fastapi.testclient import TestClient
from main import app
from config import settings

client = TestClient(app)

def make_jira_signature(body: bytes) -> str:
    sig = hmac.new(settings.JIRA_WEBHOOK_SECRET.encode(), body, hashlib.sha256).hexdigest()
    return f"sha256={sig}"

def jira_payload(labels=None):
    return {
        "webhookEvent": "jira:issue_updated",
        "issue": {"id": "12345", "fields": {"labels": labels or [{"name": "ai-task"}]}},
        "timestamp": int(time.time() * 1000),
    }

def test_jira_valid_ai_label():
    body = json.dumps(jira_payload()).encode()
    r = client.post("/webhook/jira", content=body,
                    headers={"X-Hub-Signature-256": make_jira_signature(body),
                             "Content-Type": "application/json"})
    assert r.status_code == 200

def test_jira_no_ai_label():
    body = json.dumps(jira_payload(labels=[{"name": "bug"}])).encode()
    r = client.post("/webhook/jira", content=body,
                    headers={"X-Hub-Signature-256": make_jira_signature(body),
                             "Content-Type": "application/json"})
    assert r.status_code == 200  # Still 200, just not queued

def test_jira_invalid_signature():
    body = json.dumps(jira_payload()).encode()
    r = client.post("/webhook/jira", content=body,
                    headers={"X-Hub-Signature-256": "sha256=invalid",
                             "Content-Type": "application/json"})
    assert r.status_code == 401

def test_health():
    r = client.get("/health")
    assert r.status_code == 200
    assert r.json()["status"] == "ok"
```
